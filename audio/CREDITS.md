# Ballroom quartet

Joseph Haydn — String Quartet in D major, Op. 64 No. 5 “The Lark”,
III. Menuetto. Allegretto. Performed by the **Musopen String Quartet**.

The composition is in the public domain. This recording is released under the
**Creative Commons Public Domain Mark 1.0**.

- Source: https://musopen.org/music/5261-string-quartets-hob-iii63-68/
- Wikimedia: https://commons.wikimedia.org/wiki/File:Haydn_StringQuartetInDMajorOp.64_JosephHaydn-StringQuartetInDOp.645H363Lark-03-MenuettoAllegretto.ogg
- Archive: https://archive.org/details/MusopenCollectionAsFlac

`cruise-ballroom-quartet.ogg` / `.mp3` are a local re-encode (loudness
normalization and short fades for looping), with an original light brush
and ride layer in 3/4 — no bass drum — so the on-stage drummer is heard
without covering the strings.
